# PKH-maker3 기능 및 기술 명세서 (SPEC)

다른 작업 세션이나 개발자가 이 폴더를 열었을 때 현재까지의 모든 기획·구현 상태와 추후 작업 항목을 즉시 파악할 수 있도록 정리한 문서입니다.

---

## 1. 프로젝트 개요
- **프로젝트 / Git 레포지토리명**: `PKH-maker3` (`pkh-maker3`)
- **장르**: 모바일·PC 겸용 `9:16` 세로형 무한 서바이벌 캐주얼 웹 아케이드 게임
- **핵심 컨셉**: 일반 착장의 박경호 SD 캐릭터를 좌우로 움직여 하늘에서 떨어지는 연뮤(연극·뮤지컬) 배역별 소품을 모으고, 위험 소품(`실버`)을 피하며 최대한 오래 버티는 게임. 게임 종료 시 **가장 많이 모은 소품의 배역 SD 캐릭터**로 변신한 결과 화면이 등장함.
- **배포 및 백엔드 스택**: `Cloudflare Workers (Static Assets)` + `Cloudflare D1 (SQLite 서버리스 DB)`

## 4. 확정된 게임 규칙 및 로직 명세

### 4.1 캐릭터 변신 및 동률 판정 (`determineResultCharacter`)
- **인게임 중**: 캐릭터 모습이 실시간으로 바뀌지 않고 항상 **기본 착장(`char_basic.png`)**을 유지한다. (하단 나무 바닥의 카운터 바를 통해 각 배역 소품을 몇 개 먹었는지 실시간 확인 가능)
- **게임 종료 시**: 기회 3개가 모두 차감되면 결과 화면에서 플레이 중 **가장 많이 획득한 소품의 연뮤캐**(`사이먼` / `골드문트` / `필로스` / `레미`)로 변신해 등장한다.
- **동률 처리**: 최다 획득 개수가 동률일 경우, **동률인 배역들 중 가장 마지막(최근)에 먹은 소품의 배역**으로 결정된다.
- **0개 예외 처리**: 소품을 단 1개도 먹지 못하고 종료된 경우에만 기본 캐릭터(`fallbackRole`) 결과가 표시된다.

### 4.2 점수 및 콤보 시스템 (`public/config.js` → `scoring`)
- **현재 적용 상태 (기본 점수만 활성화)**:
  - 배역 소품 8종 모두 종류에 상관없이 **1개 획득 시 `+100점`** 동일 부여.
  - `comboStepScore: 0`, `survivalTickScore: 0`으로 세팅되어 현재는 순수 획득 개수로만 점수가 올라간다.
- **확장 옵션 (구현 완료 · 설정값만 변경하면 즉시 동작)**:
  - 일반 소품을 바닥에 놓쳐 흘려보내거나 `실버`에 맞으면 `combo`가 `0`으로 초기화되는 로직이 `game.js`에 이미 구현되어 있다.
  - 추후 고객 요청 시 `config.js`에서 `comboStepScore`(예: `15`), `maxComboBonus`(예: `150`), `survivalTickScore`(예: `5`) 값만 올리면 코드 수정 없이 콤보 보너스·초당 생존 점수가 활성화된다.

### 4.3 무한 서바이벌 난이도 곡선 (`PatternDirector`)
1. **`0초 ~ 15초` (초반 구간)**:
   - 여유로운 템포로 소품과 `실버`가 낙하 (`실버` 비율 약 `34%` + 일반 소품만 연속 2회 이상 나오면 다음 스폰에 `실버` 확정 보정).
2. **`15초 ~ 26초` (중간 워밍업 구간)**:
   - 낙하 속도와 `실버` 비중(`38%~48%`), 동시 2개 낙하 빈도가 서서히 상승.
3. **`26초 ~` (고난도 리듬 패턴 코스 ↔ 숨 고르기 무한 반복)**:
   - **고난도 패턴 구간 (`11.5초` 지속)**: 무대 배경이 밤 공연장 조명으로 자연스럽게 전환되고 BGM BPM이 빨라지며, 6레인 기반의 5가지 채보 패턴(계단식 연속 낙하, 지그재그 S자 동선, 좌우 통로 이동, 교차 소나기, 양옆 좁혀오기)으로 `실버`가 몰아친다. 모든 패턴은 반드시 피할 수 있는 안전 레인을 보장한다.
   - **숨 고르기 구간 (`4.5초` 지속)**: 조명이 다시 밝아지며 일반 소품 위주로 낙하한다.
   - 위 `11.5초 ↔ 4.5초` 주기가 기회 3개를 모두 소진할 때까지 반복되며, 사이클마다 속도와 밀도가 점진 가속된다.
- **판정 보정**: 일반 소품 히트박스는 `0.92배`로 후하게, `실버` 히트박스는 `0.56배` 코어 판정으로 두어 아슬아슬하게 스쳐 피하는 조작감을 제공한다. 피격 시 `1.2초` 무적 시간 및 주변 근접 `실버` 제거로 억울한 연타 피격을 방지한다.

## 5. 유저 등록(`닉네임 + PIN`) 및 Cloudflare D1 랭킹 백엔드

- **원스텝 등록/로그인 (`POST /api/auth`)**:
  - 별도 회원가입 절차 없이 `닉네임(1~10자)` + `숫자 PIN(4~6자리)` 입력.
  - DB에 없는 닉네임이면 즉시 신규 생성(`SHA-256 + 랜덤 Salt` 해시로 PIN 암호화 저장, 평문 미저장).
  - 이미 존재하는 닉네임이면 PIN 해시 일치 여부 검증 후 로그인(불일치 시 `401` 반환하여 타인 닉네임 도용 방지).
  - 발급된 HMAC 서명 세션 토큰은 브라우저 `localStorage`에 유지되며, 비로그인 상태로 먼저 플레이하더라도 **결과 화면에서 바로 닉네임/PIN을 등록해 방금 세운 점수를 즉시 저장**할 수 있다.
- **랭킹 보드 (`GET /api/rankings`, `POST /api/score`)**:
  - 최고 점수(`best_score`) 내림차순, 동점 시 먼저 달성한 시각(`updated_at`) 오름차순 정렬.
  - 화면의 랭킹 리스트에는 **`순위 · 닉네임 · 엔딩 캐릭터 아이콘 · 최고 점수`**가 표시된다.
  - Worker 첫 실행 시 `ensureSchema()`가 자동으로 테이블 및 신규 컬럼(`best_role_counts`, `role_counts`)을 확인·생성한다.
- **관리자 페이지 (`/admin`, `public/admin.html`, `/api/admin/*`)**:
  - 관리자 비밀번호(`env.ADMIN_PASSWORD` 기본값 `0731`) 인증 후 현황 요약, 유저 & 랭킹 통합 조회(배역별 세부 수집 개수 포함, 검색/정렬/개별 삭제), 매 판 플레이 기록 로그, 점수만 초기화 / 전체 완전 초기화를 지원한다.
