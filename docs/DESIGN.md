# PKH-maker3 디자인 및 UI/UX 가이드 (DESIGN)

본 문서는 프로젝트의 시각적 톤앤매너와 UI 설계 원칙을 정의합니다. 추후 화면이나 기능을 수정할 때 아래 기준을 반드시 유지해야 합니다.

---

## 1. 최우선 디자인 원칙 (Anti-AI Cliché Rules)

1. **AI 생성물 특유의 클리셰 엄금**
   - 버튼, 제목, 플로팅 텍스트, 랭킹 목록 등에 **이모지(`🏆`, `🎭`, `⚡`, `🐹`, `✨` 등)를 넣지 않는다.**
   - 한글 타이틀 위에 영문 대문자 소제목(`STAGE ARCHIVE`, `LEADERBOARD`, `PLAYER PASS` 등)을 습관적으로 붙이지 않는다.
   - 과한 네온 그라데이션 버튼, 유리 블러(Glassmorphism) 남발, 점선 회전 후광 등을 사용하지 않는다.
2. **자연스럽고 절제된 한국어 카피**
   - 인게임 및 설명에 `'폭타 타임'`, `'리겜 코스'`, `'기니피그 목숨 3개'` 같은 어색하거나 스포일러성 표현을 쓰지 않는다.
   - 직관적이고 짧은 표현을 유지한다 (예: `좌우로 이동 · 기회는 세 번`, `닿으면 기회가 한 번 줄어듭니다`).
3. **일러스트 원본 훼손 금지**
   - 떨어지는 `실버`(폭탄)나 소품 주변에 인위적인 붉은 경고 원, 점선 테두리, 흰색 배경 원 등을 덧그리지 않고 작가님의 손그림 PNG 원본 그대로 깔끔하게 떨어뜨린다.

## 3. 화면별 레이아웃 설계 기준

### 3.1 반응형 상단 통합 헤더 바 (`.top-stage-bar`)
- 캔버스 그림과 HTML 버튼이 따로 놀아 작은 창에서 겹치는 현상을 막기 위해, **단일 Flexbox 상단바(`height: 12.6cqw`)**로 통합했다.
- 하단에 얇은 로즈·크림 스트라이프 어닝 트림(`::after`)을 두어 손그림 무대 느낌을 살렸다.
- **타이틀 상태**: 좌측 `[닉네임 등록]` 칩 / 우측 `[♪]` 원형 아이콘 버튼
- **플레이 상태**: 좌측 `[기니피그 아이콘 × 3]` / 중앙 `[00:00 | 점수]` 캡슐 / 우측 `[♪] [❚❚]` 원형 아이콘 버튼
- 모든 요소가 컨테이너 너비 단위(`cqw`)로 비례 축소되므로 창 크기를 줄여도 겹치거나 가려지지 않는다.

### 3.2 시작 화면 (`#screen-start.title-screen`)
- 답답한 모달 상자 형태를 쓰지 않고, 밝은 무대 배경 위에 바로 요소들을 배치한다.
- **구성 요소**:
  1. 상단 중앙 점선 **`로고 영역`** 박스 (추후 `config.js`의 `brand.logoImage` 입력 시 점선이 사라지고 로고 이미지 렌더링)
  2. 중앙 기본 착장 경호 SD 캐릭터 (`부드러운 상하 플로팅 모션`) + 소개 문구
  3. 하단 컨트롤 독(Dock): `좌우로 이동 · 기회는 세 번`, `시작하기` 메인 버튼, `[랭킹]` · `[게임 방법]` 보조 버튼 2개 (중복 도감 버튼 금지)

### 3.3 인게임 캔버스 (`#stage-canvas`)
- **평상시 배경 (`0~26초` 및 숨 고르기 구간)**: 밝은 크림색 벽면(`#faf5eb`) + 따뜻한 나무 무대 바닥(`#d5b58f`).
- **고난도 패턴 구간 배경 (`26초~`, `climaxBlend`)**: 별도 텍스트 배너 없이 벽면이 밤 공연장 인디고·플럼 톤(`#252136` ~ `#38273c`)으로 부드럽게 어두워지며 상단에서 은은한 스포트라이트 빛줄기 3개가 비친다.
- **하단 수집 현황 바**: 무대 바닥 영역(`y = 738`)에 4개 배역(`사이먼`, `골드문트`, `필로스`, `레미`)의 대표 아이콘과 현재까지 먹은 개수를 실시간으로 표시한다.
- **화면 흔들림 (`screenShake`)**: `updateVisualDecay()`가 게임 페이즈와 무관하게 매 프레임 감쇠시켜, 마지막 3번째 피격으로 엔딩이 날 때도 짧게 한두 번(`약 0.2초`)만 흔들리고 즉시 정지한다.

### 3.4 결과 화면 (`#screen-result`) 및 모달
- **결과 화면**:
  - 캐릭터 이미지 위에 중복되는 배역명 뱃지를 두지 않는다 (`최고 기록 경신` 시에만 상단 태그 노출).
  - 카드 상단 여백(`padding-top: 6.6cqw`)을 넉넉히 확보해 캐릭터 프레임이 위쪽 테두리에 붙어 보이지 않게 한다.
  - 점수, 버틴 시간(`00:00`), 4배역별 획득 개수 요약, 랭킹 반영 상태(비로그인 시 즉시 등록 버튼 포함)를 스크롤 없이 한 화면(`cqw` 비례)에 보여준다.
- **랭킹 모달 (`#modal-ranking`)**:
  - 각 행에는 **`순위 · 닉네임 · 최고 점수`**만 간결하게 표시한다.
  - 스크롤 영역에는 투박한 기본 스크롤바 대신 5px 두께의 얇은 반투명 커스텀 스크롤바를 적용한다.
